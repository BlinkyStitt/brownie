# JSON-RPC fixtures

`ganache.json` contains real success/revert transactions, receipts and blocks generated by Ganache CLI 6.12.2 on an isolated chain with ID 1337. Regenerate with `python tests/data/rpc/generate.py` in the pinned Python 3.8 / Ganache environment. The generator starts its own loopback-only node and checks chain 1337 before submitting local test transactions.

The `rpc_networks` fixture serves those protocol responses and explicit network headers for retired Ropsten, Rinkeby and Kovan read-only tests. It rejects unexpected RPC methods and every transaction-submission request. Development and EVM tests still execute against real Ganache. Explorer fixtures exercise source compilation, ABI fallback, proxy selection and deployment storage without a live explorer account.
